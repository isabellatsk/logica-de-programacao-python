# matriz-temperaturas-python

## Objective
A Python program that reads the temperatures (in °C) recorded over 5 days (Mon–Fri) at 4 different times of day (Morning, Afternoon, Evening, Early Morning).

The program:

- Displays the temperature table
- Calculates the average temperature for each day
- Calculates the average temperature for each time period
- Finds the highest and lowest recorded temperatures
- Allows temperature lookup by day and time period

## How to run

Make sure Python is installed.

Run:

```bash
python main.py
```

## Example
Input
- Seg - Morning: 20
- Seg - Afternoon: 28
- Seg - Night: 18
- Seg - Dawn: 15

Output
- Temperature Table
- Average per Day
- Average per Time Period
- Highest Temperature
- Lowest Temperature
- Temperature Lookup
